Engine feedback. Scene hierarchies and geometry/material composition made procedural art straightforward. The default WebGL fallback was surprising; this game explicitly disables it. Mission direction, flight feel, combat, targeting, UI and audio were built here. Coordinating physics and rendering was the hardest part. I would replace implicit backend fallback with an explicit WebGPU-only option.
