NEBULA KITE

CORSAIR RUN // ONE-WAY STRIKE

Punch through the asteroid relay, break the raider screen, and destroy the command carrier before it closes the jump gate.

WASD / ARROWS steer
SPACE / CLICK laser
SHIFT boost
CTRL brake
Q / E bank; double-tap roll
B Nova Bomb
P / ESC pause
R restart

Mouse: move pointer to steer. Click to fire. Keyboard and mouse can be mixed.

Audio starts after launch. No network connection is used.
