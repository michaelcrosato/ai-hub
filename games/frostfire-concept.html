FROSTFIRE / FIELD NOTES

How to present.

Use the arrow buttons, slide dots, or Left and Right keys. Press F for full screen. Press P to pause motion. Press 1, 2, or 3 for a visible scene or combat action.

This is a standalone design prototype. Scene choices, the room map, and combat use small scripted examples. They are not connected to the AdventureForge engine.

WebGPU and fallback

The WebGPU version uses a WGSL scene shader, a compute pass for particles, and an instanced render pass. A Canvas 2D version runs when WebGPU is not available or fails. The status badge shows the renderer in use.

For the WebGPU version, open this file through HTTPS or a local web server in a browser with WebGPU support. No build, account, API key, or game server is needed.

From this folder, run python -m http.server 8000. Then open http://localhost:8000/frostfire-presentation.html.
