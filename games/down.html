DOWN / SELENE EXTRACTION
An original six-axis mine combat game. One complete mission, made as a tribute to the feel of 1990s PC tunnel shooters.

Recover two keys. Rescue three crew members. Destroy the reactor, then find the exit before the timer ends. The route guide can help you through the mine. Use G to turn it off.

The renderer, level, models, textures, music, and sound effects are included in this file. No network connection or install is needed. Built with JavaScript, WebGL, and Web Audio. No third-party code or game assets are used.

This is an independent fan-made work. It is not an official Descent game. Descent is a reference for the design, not the source of the assets.

Settings and best scores stay in this browser when local storage is available. A keyboard, mouse, and WebGL are required. Progress resets when you close the file.
