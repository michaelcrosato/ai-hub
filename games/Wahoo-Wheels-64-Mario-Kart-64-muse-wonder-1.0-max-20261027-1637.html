About / Credits

Wahoo Wheels 64 is an original spiritual successor to Mario Kart 64 (N64). No Nintendo assets are used; every kart, racer and track is drawn in code.

Date: 2026-10-27 16:37 · Source: Mario Kart 64 for N64

Tech: Three.js 0.180.0 WebGPURenderer (WebGPU only, no fallback), Rapier 0.19.3 physics via @dimforge/rapier3d-compat, Web Audio, Gamepad API.

Art: Stylized cel-shaded toon materials, 4-step gradient, inverted-hull outlines. Animation: procedural (wheel spin, hop squash, drift lean, spring cameras).

Testing: lightweight — syntax parse, CDN reachability, DOM harness smoke. No screenshots or subagent reviews per brief.

Environment: Muse Code CLI (headless); Linux; browser unknown. Model: Meta, muse-wonder-1.0, reasoning effort max. Usage: unknown.

How to play: Steer, hop into a drift, charge blue → orange → purple, let go for boost. Grab a glowing Item Box, bonk rivals, dodge bananas. Three laps. First to the chequered flag gets the big shiny cup and bragging rights until the next race.
