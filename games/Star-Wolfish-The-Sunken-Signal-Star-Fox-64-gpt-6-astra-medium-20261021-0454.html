Source information · Inspired by StarFox 64. Star Wolfish is an original procedural work; all aircraft, scenery and sounds are created in code. Date: 2026-10-21 04:55 America/Vancouver.

Tech · Three.js R180 (0.180.0), WebGPU only; Rapier 0.19.3; Web Audio; Gamepad API. Art: geometric coastal science fiction. Animation: procedural banking, formation paths, camera springs and debris; fixed 60 Hz physics sensors.

Environment / model · Codex CLI, Ubuntu / WSL2; headless Chrome 154.0.8037.57 (software WebGPU for checks). OpenAI gpt-6-astra, medium reasoning (requested). Usage: Session time 14m 50s; tokens 1,358,497 total (1,329,883 input including 1,270,400 cached and 0 cache-write; 28,614 output including 4,816 reasoning); API cost $3.295930 USD (Estimated standard API token cost; not subscription billing)..

Testing · Five text-only Playwright 1.56.1 / headless Chrome 154.0.8037.57 browser runs, plus two JavaScript syntax checks. Two issues found: one critical intermittent Rapier collider-churn crash and one noncritical missing favicon; both addressed. Final browser run passed WebGPU boot, ten-second attract entry, 300 seconds of accelerated attract simulation including carrier and restart loop, attract interruption, keyboard fire/roll/nova/steering/pause, simulated standard-gamepad Options and horizontal/vertical inversion. No visual testing. Physical PS5 hardware was not tested. Test cost unknown.

Engine feedback · Best: Three.js scene composition and WebGPU materials. R180 silently offers a WebGL fallback by default; source inspection identified how to disable it. Sustained flight exposed a Rapier 0.19.3 crash matching upstream issue 363; preallocated reusable physics bodies and filtered collision groups resolved it in the final run. The most important custom system was the mission director connecting route choice, squad rescues, combat and boss phases. The hardest engine integration was physics object lifecycle under continuous spawning. Overhaul: improve collider-churn stability and WASM error diagnostics. Requested change: a public strict-WebGPU initialization option. Upstream report.

Prompt feedback · 404299fcd4 · The controller-first brief and packaging were clear. “Feature-complete engine” has open-ended scope; this implementation defines it as a complete replayable mission. Teaching the full moveset without dense UI was hardest. Extra test desired: a physical PS5 controller playthrough, including reconnect, inversions and boss retry.
