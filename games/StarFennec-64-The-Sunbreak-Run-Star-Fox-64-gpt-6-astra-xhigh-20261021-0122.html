Engine Feedback

What did you like most about the engine?
Three.js makes procedural geometry, scene composition, lighting and node-based bloom fit together cleanly; Rapier supplies the collision and rigid-body layer.

Did you get stuck or guess wrong?
Three.js r180 enables automatic WebGL fallback, conflicting with this brief. Pinned source inspection identified the fallback callback, which is explicitly disabled before initialization. Runtime behavior remains unverified.

What was the most important thing you had to build yourself?
The arcade flight and combat layer: input abstraction, homing weapons, reflection, mission scheduling, branching progression, squad behavior, checkpoints, AI demonstration and debrief.

What was the hardest part about using the engine?
Coordinating fixed-step physics, target acquisition, camera motion and transitions between rail and all-range flight.

If you had to remove or overhaul one thing from the engine, what would that be?
Replace the private fallback opt-out with a documented strict-WebGPU configuration.

If you could change one thing about the engine, what would it be?
Provide a compact reference project combining gamepad input, swept projectiles and fixed-step game simulation with the WebGPU renderer.
