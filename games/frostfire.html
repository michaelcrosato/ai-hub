Preparing the renderer.

WebGPU: The GPU draws both scene textures and effects. A compute shader updates the particles. The 2D fallback runs when WebGPU is not available. The status label reports the active renderer.

Local launch: Serve this file through localhost or HTTPS. From its folder, run python -m http.server 8000. Open http://localhost:8000/frostfire-worlds.html. No build, account, game server, or external asset download is needed.

Demo only: These choices use small sample rules. Art, dialogue, and location links are a design study, not a copy of the game world. The journal is kept only in this tab. It is not a game save.
