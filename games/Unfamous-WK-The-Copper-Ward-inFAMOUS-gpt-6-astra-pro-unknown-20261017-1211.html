Field notes

Initial date
17 October 2026.
SOURCE
inFAMOUS for PlayStation 3. Inspiration reference only. This game uses an original city, cast, story, visual assets, and code.
Game engine
Stormline Engine 1.0.0, a custom game framework with Three.js 0.178.0. Handoff: Unfamous-WK.html.
Environment
Built in the ChatGPT cloud workspace on Linux. Runs in a desktop browser with WebGL 2. Browser test details are in the source readme.
Model / effort
OpenAI · GPT-6 Astra Pro. The reasoning effort setting is not confirmed.

Made from model knowledge. No web search was used. The graphics, characters, city, music, and sound effects are generated by the code. Three.js is included under the MIT license. Its license is preserved in the source.
