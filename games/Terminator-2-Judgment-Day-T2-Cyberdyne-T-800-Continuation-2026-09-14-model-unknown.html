Editing rules and source format

The actual runtime code is stored in script[data-strata-module] tags near the end of this file. These tags contain plain JavaScript. They are not encrypted or compressed. Edit them, save the HTML, and reload it.

<script type="text/plain" data-strata-module="episode/new-rule.js">
import { Scope } from 'strata/kit/scope.js';
// Put the episode-specific rule here.
</script>

Add new module tags before #strata-bootstrap. Use unique paths and the strata/ import prefix. Do not use relative module imports inside the HTML. The loader creates the module map from the tags.

Keep library versions pinned. Use one fixed-step simulation. Register cleanup with Scope. Keep saves as bounded JSON. Do not add a new framework for one mechanic.

Do not place a literal closing script tag in a JavaScript string or comment. Use \u003c for the less-than sign in such strings. Keep module IDs stable unless their imports also change.

Change saveId for a new game. Update the game title, objective text, and local rules together. Use the Reset control when changed settings make an old save invalid.

There is one source copy. The source browser below shows the same code that the sample uses. It is read-only; use an agent or code editor to make changes.

03 / Structure

Share the basics. Keep the game local.

The FPS starter owns common movement, physics, and input. The sample owns its level, enemies, weapon presentation, and objective. The page contract can connect other games without making them use the FPS starter.

Reuse

Game-loop hooks and a local behavior
const game = await FpsGame.create(host, level, {
  configure({ prefabs, schemas, behaviors }) {
    // Register custom definitions before level validation.
  },
  beforeStep(dt, game) { /* Fixed-step game rules. */ },
  afterStep(dt, game)  { /* Read physics results. */ },
  render(dt, game)     { /* Visual-only changes. */ },
  mode(running)       { /* Show or hide the pause screen. */ },
  notice(text)        { /* Show status and errors. */ }
});

// Call from a user click after create() resolves.
playButton.onclick = () => game.play();
// Dispose before creating a replacement runtime.
game.dispose();

Add a custom component through the behavior registry. It installs the validator and factory together.

behaviors.register('read-note', data => {
  if (typeof data.text !== 'string' || !data.text.trim() || data.text.length > 240)
    throw new Error('The note needs 1–240 characters.');
}, (entity, data, context) => ({
  prompt: () => 'Read note',
  interact: () => context.notify(data.text)
}));

Then add {"type":"read-note","text":"The gate is locked."} to an entity’s components. Use a collider that the interaction ray can reach.

Coordinates, prefabs, and signals

One unit is one meter. Y is up. The default view faces negative Z. Level rotations use degrees. Each scale axis must be from 0.05 through 100. A level must have exactly one spawn component.

Visuals and colliders are separate prefab data. Sensor-based components need sensor colliders. A trigger component alone does not turn a solid block into a sensor.

{"type":"door","channel":"gate","axis":"y","distance":3.6,"speed":2}

// A switch, pickup, or local rule can open that door:
game.runtime.signals.send('gate', true, 'local-rule');

Built-in components include switches, doors, movers, triggers, pickups, checkpoints, jump pads, hazards, goals, delays, counters, and all/any logic.

Standalone completion versus another HTML page

The scene continues through police waves. Select End run in the pause menu to save a result and stop. The game does not load a separate driving episode.

For a real collection, replace the standalone adapter with connectEpisode. Serve the pages and a campaign manifest from the same origin. Give each page its own runtime. Use a named exit and plain JSON to connect them.

session.complete('drive', {
  local: { defeated: ['guard-a', 'guard-b', 'guard-c'] },
  shared: { ...session.shared, 'yard-cleared': true, health: 72 }
});

The manifest must define that exit. Do not pass meshes, DOM nodes, callbacks, or physics handles. This page contract is not a security sandbox for untrusted code.

05 / Checks & limits
Check the base before you extend it.

  
The embedded checks test pure game logic. They do not need the CDN libraries. They do not prove that rendering, collision, or complete gameplay works.

  
SOURCE + LOGIC CHECKS
128 pure logic checks passed in Node.js and Chromium. Syntax and local import checks passed for 33 modules. 28 component checks passed with explicit test doubles. They do not verify real 3D physics.
3D TEST LIMIT
Real 3D rendering, Rapier motion, sound output, and a complete play-through are not verified. Runtime library downloads failed. WebGL was unavailable for the two optical shader checks.

One file to hand to an agent. Not a fully offline game. All custom code, procedural asset definitions, tests, and instructions are embedded. Three.js 0.180.0 and Rapier 0.19.3 load from pinned CDN URLs when the sample starts.

  
Run and test the sample

    
Open this file in a desktop browser. Select Launch Cyberdyne scene, then select the play button after the libraries load. Use WASD to move, Shift to sprint, Space to jump, C or Ctrl to crouch, E to use or carry, click to fire or throw, R to reload, T to respawn, and Esc to pause.

    
Disable the opening 8 vehicles. The first response wave starts after a 12-second break. Press Tab for T-800 optics. Hold the right mouse button to zoom. The green lab panel repairs and reloads the player. Pause to save, export, import, or end the run.

    
A local file launch is intended, but it was not verified here. When a browser blocks local modules or mouse capture, serve the folder instead:


python -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000/t2-cyberdyne.html

    
Do not test play in a restricted email viewer or an embedded attachment preview. A blocked mouse-capture request is shown as an error. Exported source can be checked with node tests/run.mjs.

    
After a change, test startup, pause, movement, blocked standing, collision, shooting, carrying, reload, death, saves, completion, and repeated launches. Record what actually ran.

  

  
Scope, dependencies, and license
This file contains the FPS starter, not the earlier spatial editor or driving sample. It does not include multiplayer, a general navigation system, touch controls, or a complete animation system.
The Strata source uses the MIT license included in the source browser and export. Third-party libraries retain their own terms. No API key or model service is required by this file.
The optional GLB adapter loads a separate asset file. Additional models, textures, sound files, or libraries must be packaged separately or embedded for a future fully offline game.
