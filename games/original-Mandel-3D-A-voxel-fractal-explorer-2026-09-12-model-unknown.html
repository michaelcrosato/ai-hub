    Explore in 3D.

    Drag to rotate the camera. Inspect the top, walls, or underside. Each block is a cube. Height shows escape time; the fractal itself remains two-dimensional.

    Camera movement does not change the fractal location. Families: Mandelbrot, Julia (the Julia set of any point you visit), Burning Ship, Tricorn and the cubic Multibrot. Adaptive mode uses fewer cubes during movement on slower devices, then restores the full view. Press C if the terrain leaves the view.
