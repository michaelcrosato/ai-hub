The fine print

About / credits

A love letter to the glorious side-scrolling brawlers of the arcade era.

Source information

Date: 2026-10-29 09:24. Source: Turtles in Time. Created as an original arcade brawler inspired by the source.

Tech: Three.js R180 WebGPU, Rapier 0.19.3, Web Audio, Gamepad API, PeerJS 1.5.5 and AI Hub Session Protocol v1. WebGPU is required.

Art direction: colorful cel-shaded, chunky low-poly street scenes and original procedural characters. Animation: procedural joint posing and physics-query combat. Audio: original code-synthesized music, effects and gibberish voices. Online: AI Hub co-op sessions and standalone PeerJS rooms, up to four players.

Testing: lightweight browser and integration checks. Environment: Codex CLI (headless); Linux; browser unknown. Model: OpenAI, gpt-6.1-terra, reasoning effort ultra. Usage: unknown.

Testing feedback

Issues caught during testing: 1 (headless Chrome graphics configuration). Critical game defects caught: 0. Most helpful: headless WebGPU browser smoke test. Least helpful: static syntax check.

Engine feedback

Three.js makes it straightforward to compose expressive 3D scenes. WebGPU startup and compatibility require care; Rapier query timing needed verification. The combat, animation, encounters and networking had to be built for this game. The hardest part was coordinating a shared multiplayer simulation. A higher-level character and combat toolkit would make this engine easier to use; clearer WebGPU diagnostics would improve it.

Prompt feedback

The strongest part was the clear arcade inspiration and controller-first direction. The exact interpretation of standalone multiplayer was open. The hardest task was creating a complete networked vertical slice in a single file. The most valuable additional test would be a full cross-device co-op playthrough on real controllers.
