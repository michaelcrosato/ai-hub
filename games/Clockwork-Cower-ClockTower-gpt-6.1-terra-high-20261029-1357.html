About & credits

Clockwork Cower · An original spiritual successor to ClockTower. Built for a controller-first, ten-foot experience.

Source information. 2026-10-29 13:57. Source: ClockTower. Three.js r180, WebGPU only, Rapier 0.19.3, Gamepad API, Web Audio, AI Hub session protocol. Art: cel-shaded gothic miniatures. Animation: procedural. Audio: original synthesized music and effects, no voice. Online: AI Hub parallel sessions; no direct shared-world play. Testing: lightweight viewport and browser checks. Environment: Codex CLI (headless), Linux, browser unknown. Model: OpenAI gpt-6.1-terra, high reasoning. Usage: unknown.

Engine feedback. Three.js makes scene composition approachable. Browser WebGPU support is the hardest constraint. Stealth, puzzles, movement and controller navigation were built for this slice. More consistent WebGPU availability would help; no engine feature was removed.

Prompt feedback. The controller-first direction and attract mode are excellent constraints. Multiplayer did not specify shared-world or parallel play, so documented AI Hub parallel mode was chosen. The hardest part was a complete horror slice in one file. The best further test would be a long real-device controller playthrough.

Testing feedback. Results and limitations are reported with delivery; test counts are unknown in this build.
