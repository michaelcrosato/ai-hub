Design and connection points

An overworld, ready for its games.

What works now

A photographic 2D opening changes into a pixel-art world. Walk, talk, find three memories, open the sealed route, use waystones, and save progress. Each region has a place, a story, and an entrance.

Keyboard: WASD / arrows to move, Shift to run, E / Space to use, M for the map, J for notes, and Escape for the menu. You can also click a path to walk or use the touch controls.

What is not built

The games behind the entrances are not included. Combat, shops, and building interiors are not included. No game win or reward is added when you visit an empty stage.

This file has no server or external files. Save data uses this browser's storage. Export and import are available when browser storage is blocked.
