ABOUT / CREDITS

Oopsy-Forgot Planets — an original spiritual successor to Forgotten Worlds (1988). One polished sector: the ruined sky-city of Dustopia, a mid-mission Sky Shop, orbiting satellite gunplay and a junk-wyrm boss.

• Initial Date: 2026-10-17
• SOURCE: Forgotten Worlds (1988, Capcom) — inspiration only; all code, art & audio original
• Tech/Engine: Vanilla JS (ES2023) + HTML5 Canvas 2D + Web Audio API + Gamepad API, no external libraries. Single-file build for modern Chrome/Edge (2025).
• Environment: Muse Code CLI, Linux WSL2, Chrome/Edge
• Model and Effort Level: Meta muse-wonder-1.0, reasoning effort unknown

What I liked about the prompt: the sharp constraints (single file, attract mode, controller-first) forced real arcade discipline. What was confusing: “versions released in 2025” for a no-library build — resolved by using only evergreen platform APIs. Hardest: making 360° twin-stick aim, gamepad-only menus and an AI attract pilot all feel right in one file with zero console errors.
