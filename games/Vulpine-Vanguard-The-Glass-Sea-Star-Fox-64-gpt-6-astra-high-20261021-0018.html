The expedition.

Vulpine Vanguard is an original arcade flight adventure inspired by StarFox 64. Original spacecraft, characters, scenery, and procedural audio; no source-game assets.

Engine Feedback

Liked most: Three.js makes a complete procedural scene graph practical in a portable browser game, while Rapier provides reliable collision primitives and debris motion.

Stuck / wrong guess: WebGPURenderer enables WebGL fallback by default. The pinned r180 implementation was inspected and its fallback callback explicitly disabled.

Built ourselves: the mission scheduler, flight model, targeting, squadron behavior, encounter logic, controller navigation, checkpoints and adaptive synthesizer.

Hardest part: coordinating a fixed-step physics world with forward-scrolling scenery, lock-on targeting and cinematic flight animation.

Remove or overhaul: implicit backend fallback when a project requires WebGPU.
One engine change: provide a public, explicit WebGPU-only initialization option with clear capability errors.

Prompt Feedback · version 404299fcd4

Liked most: the controller-first requirement, concrete single-file delivery, and the attract mode requirement give the demo a clear arcade identity.

Confusing: “feature-complete” and “normal designer tools” do not define a finite campaign scope. This demo interprets them as a complete replayable mission and editable data-driven encounter definitions.

Hardest part: making branching objectives, readable flight combat and a multi-phase boss cohere in one portable file without a rendering review.

One test we would run: a full PS5-controller playthrough on a real WebGPU browser, covering both routes, hot-plugging, checkpoint retry and the final boss. This was not run because visual testing was excluded.
