Original flight / Familiar spirit

Astro Fennec is an original arcade flight game inspired by StarFox 64. All spacecraft, characters, terrain, effects, interface, and synthesized audio were created for this demo. No source-game assets are used. Title selected from 50 candidates using Python’s secrets random-number generator.

Source Information

Date: 2026-10-21 06:43 UTC. Source: StarFox 64. Title: Astro Fennec, selected from 50 candidates using a real random-number generator. Tech: Three.js r180 (0.180.0), WebGPU only with fallback disabled, TSL bloom, Rapier 3D 0.19.3, Web Audio API, Gamepad API, JavaScript, HTML/CSS. Art Direction: sun-washed, low-poly retrofuturism; ivory interceptors, stratified sandstone, turquoise engines, monumental solar machinery. Animation: procedural flight transforms, banking, rolls and somersaults, homing trajectories, Rapier rigid-body debris, fixed 60 Hz simulation, smoothed chase camera, procedural particles. Environment: Codex CLI; verified Ubuntu 26.04.1 LTS / WSL2, Linux 6.18.33.2-microsoft-standard-WSL2; Google Chrome 154.0.8037.57, Playwright 1.63.0, software Vulkan WebGPU test adapter. Model: OpenAI, gpt-6-astra, high reasoning (supplied execution identity).

Testing

Four gameplay/interface suite runs: the final expanded suite passes all 35 checks with no runtime errors. One compatibility suite passes all 4 checks: unsupported WebGPU, failed CDN, direct file-URL launch, and touch-only notice/settings. Also performed 4 startup smoke runs, 3 GPU-render/capture probes, 1 initial visual run, and 3 five-view visual-review runs, including 1440×900 and 960×540 layouts. JavaScript syntax checks and Python lint/format checks pass. Browser testing found 3 game defects, all fixed: missing WebGPU import-map alias (critical startup failure), stale Rapier body cleanup on restart (critical simulation failure), and HUD overlays showing over paused menus (noncritical). Separately, headless Chrome omitted the WebGPU canvas from ordinary screenshots; exact GPU readbacks were composited with the HTML HUD for visual review only. Rapier emits one upstream initialization deprecation warning. Physical PS5 controller testing and hardware GPU presentation: unknown. Test cost: unknown.

Engine Feedback

Most liked: Three.js scene composition and TSL bloom made the procedural world straightforward to assemble. Stuck / guessed wrong: the bloom addon also needs the three/webgpu import alias; removed Rapier bodies must not be removed a second time through stale wrappers. Most important custom system: a fixed-step arcade mission director joining flight, collision events, target locks, route objectives, checkpoints, scoring, and controller navigation. Hardest part: coordinating camera-relative aiming and physics timing across rail and all-range flight. Overhaul: make the renderer’s automatic fallback explicitly opt-in. One change: provide a stable public WebGPU-only initialization option with a clear device-loss lifecycle.
