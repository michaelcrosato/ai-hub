Read the sight.

Steer the large sight over a target. Shots travel towards it. Hold fire for a continuous stream.

Return the fire.

Roll through pink energy shots. Each return builds charge. Full charge starts eight seconds of stronger fire.

Watch the colour.

Pink shots can be returned. Orange missiles and solid structures must be avoided. Cyan rings repair the hull.

Pick a line.

At the route split, steer left for the service cut. Stay right for open water. Both routes reach the carrier.

Touch controls appear on touch screens. For mouse steering, select Mouse / pointer in Settings. Press any controller button to connect it.

Credits & field notes

An original flight operation

Game design, spacecraft, scenery, music, sound, and mission text were created for this slice. No Nintendo game assets are used.

Engine foundation

Built on my-3D2dge Agent Edition v0.12.1 by Michael Crosato. The engine provides the game loop, scenes, input, audio, and storage. IONWAKE adds perspective drawing, flight combat, and WebGPU image filters.

Design research

The flight and obstacle design takes inspiration from Star Fox for the SNES. The return-charge system, local route choice, and score chain are new design choices.

  • Nintendo · Star Fox manual
  • StrategyWiki · Gameplay guide
  • StrategyWiki · First route guide

Build notes

Flight records and settings stay on this device. WebGPU filters need a browser and graphics device that support WebGPU. If a filter cannot start, the original display stays active.

This is one complete level. It has no additional campaign levels. Engine code uses the MIT licence.
