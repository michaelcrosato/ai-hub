# Character model

1. Download the Standard (free, CC0) pack from https://quaternius.itch.io/universal-animation-library
2. Optional glTF mirror: https://github.com/J-Ponzo/gltf-universal-animation-library
3. Copy a GLB that contains a humanoid mesh + animation clips to public/models/character.glb
4. Prefer a no-root-motion export if both variants exist
5. Do not add Mixamo source files to this repo
