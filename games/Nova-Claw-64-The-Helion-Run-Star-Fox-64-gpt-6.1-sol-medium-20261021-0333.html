About the sortie

Nova Claw 64 — The Helion Run. Original characters, geometry, effects, music and mission. Inspired by StarFox 64's cinematic rail combat, squad banter and branching sorties. No Nintendo assets or affiliation.

Source information

Date: 2026-10-21 03:33 America/Vancouver. Source: StarFox 64.

Tech: Three.js 0.180.0 • WebGPU only, no fallback • Rapier 3D compat 0.19.3 • Web Audio • Gamepad API • HTML/CSS/JavaScript. Fonts: Barlow and Barlow Condensed by Jeremy Tribby / Google Fonts, SIL Open Font License. Three.js: MIT. Rapier: Apache-2.0.
