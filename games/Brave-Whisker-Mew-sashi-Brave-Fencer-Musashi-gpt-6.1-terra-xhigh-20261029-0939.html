The tiny print

About this adventure

Source information. 2026-10-29 09:39 · Inspired by Brave Fencer Musashi. Original game by OpenAI Codex, model gpt-6.1-terra, reasoning effort xhigh. Environment: Codex CLI (headless); Linux; browser unknown. Usage: unknown.

Tech & craft. Three.js r180 with WebGPU only; Rapier 0.19.3; Web Audio and Gamepad APIs; AI Hub Session Protocol v1. Cel-shaded storybook forms, procedural character animation, synthesized music, effects and gibberish voices. AI Hub side-by-side sessions and standalone couch co-op. Testing: headless Chrome 154, static checks and a two-player AI Hub harness; no physical controller or hardware WebGPU display test.

Testing feedback. Two issues caught: a blank headless WebGPU surface and blocked attract audio; one was game-breaking in that test environment. Most helpful: browser gameplay and hub harness checks. Least helpful: the headless screenshot, because the compositor surface failed. A real controller and hardware display remain untested.

Engine feedback. Three.js makes procedural scenes approachable. WebGPU support and headless GPU availability needed investigation. The quest, combat, animation and controller systems were built for this game. Validation was hardest. Overhaul renderer diagnostics; clearer initialization and material migration errors would help.

Prompt feedback. The source and controller-first direction were useful. Standalone multiplayer transport was unspecified, so couch co-op was chosen. A cohesive action-adventure slice in one file was the hardest part. A real DualSense and WebGPU playthrough would be the most useful additional test.
