BUILD NOTES / CREDITS / COMPLETION REPORT

Iron Circuit

A complete, remixed Metal Man factory mission inspired by Mega Man 2 for NES. Side-view run-and-gun action, a Robot Master, and a usable weapon-copy reward.

Generation: 2026-09-27 · Model: GPT-6 Astra Pro · Engine: CO55 0.4.0. Internal, non-commercial fan demonstration. Mega Man characters, names and original game are associated with Capcom; this build is not affiliated with or endorsed by Capcom.

Launch & save

Open this HTML file directly in a browser with JavaScript enabled. No installation, server, network access, CDN or external asset is required. Press Start Mission. Sound begins after a click, key or touch. Chrome/Chromium is the tested browser; other modern browsers are intended but not certified. Landscape is recommended on touch devices.

Checkpoints, inventory at the checkpoint, settings and best clear time use localStorage. Continue restores the last checkpoint, not the exact mid-air position. If browser privacy settings block storage, the game remains playable but saves last only for the current session. Retry restores checkpoint inventory and resets encounters; the cumulative time and retry count continue. Finishing enables an Encore replay with Metal Blade.

Source basis & selection

No source guide was supplied. The references below informed the content checklist. The map's upper route → vertical transfer → lower gear/conveyor route → final ascent → boss structure is adapted rather than reproduced tile-for-tile. New names for sectors and all dialogue are original.

VGMaps: Mega Man II — Metal Man stage map (layout reference, not embedded artwork). MMHP: Mega Man 2 Data Base (weapons, pickups, enemy behaviors and boss damage). MMHP: Mega Man 2 Game Hints (boss strategies and critique). Accessed during this build. Links are documentation only and are never fetched by the game.

MMHP praises the memorable music and charm but criticizes delayed movement and difficulty revisiting stages. This adaptation uses immediate directional response, buffered variable-height jumps, compact checkpoints and an Encore replay. No claim is made that these choices represent every player's preference.

Explicit adaptations & additions

All level distances, platform dimensions, hazard timings and enemy placement are a designed remix, not a frame-accurate remake. Press lamps and floor warnings, sector signs, extra checkpoints, short retry loops, item-cache ladders, pause-safe menus, eight-direction touch input, variable-height jump buffering, scenery layers and the three-target extraction gallery are additions. Some refill placement is rebalanced. No sliding, charging the normal buster or dashing has been added.

Quick Boomerang and Item-2 are available from the start solely to demonstrate weapon energy, boss weaknesses and utility traversal within one level. In the original they come from other stages. Quick Boomerang costs one-eighth energy per shot; Item-2 deploys a delayed, straight-flying rideable sled. A full-energy Metal Blade is earned here, not provided on a fresh first run. Encore starts with that earned weapon. The cache route is optional; no mandatory jump requires consumable energy.

Engine integration & extensions

The inlined engine script and embedded API card are retained unchanged. Only the game section and surrounding presentation are replaced. All gameplay positions are world-space x/z; y is a depth lane. CO55 provides the timing loop, input, side projection, rendering queue, pixel primitives, font, camera smoothing, particles, lights and hit presentation. Game-specific code adds swept axis collision against solid/one-way platforms, ladders, conveyor transport, projectiles, jets, enemy states, inventory, persistence and UI. Characters are procedural articulated rigs driven by gait phases, action timers, two-bone IK and spring squash; there are no animation sprite sheets.

The game intentionally uses Canvas lighting. The strict side view has no inverse ground projection, so the optional engine WebGPU lighting is not activated. Its implementation and automatic fallback remain intact. Pixel-light and unlit modes are both playable. Crisp integer buffer scaling and disabled image smoothing are preserved. All new game-buffer shapes use CO55.px; text uses CO55.font.

Not performed & known limitations

Audio exception: requested source-game recordings could not be downloaded. The embedded music and effects are original synthesized substitutes; the source-audio sourcing requirement remains unmet.

File-URL launch: this environment's managed Chromium policy blocked direct navigation to local file URLs. The exact self-contained HTML was instead loaded into the browser with networking disabled and tested there. A normal native double-click/file-URL launch could not be verified in this environment. The file contains no server-dependent code or external runtime resources.

Untested environments: physical phones, physical gamepads, Safari, Firefox, iOS Web Audio, device-specific fullscreen policies, extended thermal/battery behavior and sustained flagship-phone frame rates were not tested. Mobile touch and gamepad results above are emulated/simulated, not hardware certification.

Saving: native localStorage persistence across closing/reopening a local file was not verified. File-origin storage behavior and private-browsing restrictions vary by browser. When storage is denied, a same-page memory fallback supports retries and Continue, but refreshing or closing the document loses that session. Moving or renaming the HTML may also change its storage location.

Adaptation scope: the map and action timings are intentionally remixed, not original ROM emulation or a tile-perfect reconstruction. Quick Boomerang and Item-2 are preloaded demo equipment; the post-boss weapon trial and Encore are additions. Landscape is recommended on touch screens. No progression blocker was observed in the tested complete routes.

Excluded scope

The seven other Robot Master levels, Wily fortress stages, stage-order selection, remaining weapons, Item-1/Item-3, original passwords and full-game story/ending are outside this single-level slice. The extraction gallery and its results are the ending of this demo, not a recreation of Mega Man 2's full-game ending. Source recordings could not be retrieved; that audio sourcing requirement remains unmet.
