## How the two sides were matched

1. **Byte-identical** (SHA-256): 149 files. The wall's file was renamed to the folder's name.
2. **Same title, same game code**: 74 files. The folder's copy is an offline
   bundle of the same build: the libraries a page loads from a CDN (three.js,
   Babylon.js, React) are inlined as base64, and the code is re-emitted by a
   bundler. The bundle adds no game text of its own, only library code, so they
   are one version of one game. The wall keeps its lean build, renamed:
   *HOT TREADS* is 115 KB on the wall and 22.8 MB bundled.
   Project folders (Aetherfall, Pennywing, Runeclash…) stay folders.
3. **Same title, the wall's build is newer**: kept the wall's build, renamed.
   - Little World — Sing, play, grow — hub build is newer (voice storage schema v2 vs v1)
   - Plus One — A life of your own — hub build has session content the GPT copy lacks
   - Singularity Tycoon — A history of intelligence — hub build has lessons and win conditions the GPT copy lacks
4. **Different titles, one lineage**: text shared between files (with library
   strings discounted) found the few renamed iterations; each was read to see
   which is newer.
5. **Everything else is a separate game** — including same-idea attempts whose
   code is unrelated (the two BLACKWELLs, Kinetic and Kinetic Studio, Form and
   Form Lab, the Endless Sky and Final Fantasy sets), as in the first curation.
