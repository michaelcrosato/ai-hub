# Library curation — 24 Sep 2026

> The slugs below are the ones used before the 28 Sep import renamed every
> game by source; `curation-2026-09-28.md` maps them to the current ones.

The Google Drive folder held 396 files (371 HTML, 25 zips), uploaded newest
first. That upload order is the only surviving record of when each file was
made (Drive stamps every file with the upload time), and version numbers
confirm it: `days-of-daytona-usa-v12` was uploaded 3rd, `v1` 339th.

## How iterations were told apart from separate attempts

Every file was fingerprinted on its code alone: inline images, audio and
fonts stripped, and code shared across unrelated titles (three.js and other
bundled libraries) ignored. Two files belong to the same lineage when they
share most of that code (Jaccard ≥ 0.4, or one contains ≥ 80% of the
other), or ≥ 0.6 when their titles differ (renames such as BOUNDLESS → Void
Explorer, RUNOUT → SUPER RUNOUT). Separate prompts for the same idea produce
unrelated code (similarity ≈ 0) and were all kept — three Plus Ones, three
Wildlands, two Good Companies and so on. From each lineage only the newest
file was kept.

Exceptions, by judgement: Pocket Parade and its "Chapter 02" sequel both
stay. The Night Signal PlayCanvas starter is TypeScript source that needs a
build (kept in `sources/`, not on the wall). The Strata Episode Kit was built
with its own CDN build script and the result is on the wall; its source is
in `sources/`.
