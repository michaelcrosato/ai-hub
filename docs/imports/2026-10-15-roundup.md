## Repair and validation

Astral Crest originally rendered a blank canvas: its static router shim discarded the route's head-script declarations. A focused patch loads the seven already-embedded dependencies in order, then boots. Desktop and mobile checks reached its field scene without page errors. Two regression tests cover ordered startup and refusal to boot after a dependency load failure. The exact replacement and original/installed hashes are in [the patch record](2026-10-15-astral-crest-patch.json).

Checks cover Chromium startup, available start controls, short keyboard/mouse/touch input and screenshots at desktop and mobile viewports. Mobile games were generally checked at 844×390; editors additionally at 390×844 and 1440×900. Some mobile checks used keyboard fallback. No full campaigns, physical phones, physical controllers, Firefox or Safari were tested. Automated click/screenshot timeouts are retained in the browser evidence rather than counted as successes; selected retries and visible scene inspection establish the narrower results below.

**Six titles need hardware WebGPU review:** Ashlar Wake, Cinder Ford, Cinder Nave, Frostline, Hard Light and Lantern. Their menus/HUDs appeared, but software WebGPU produced device errors, persistent loading or an unverified world render. Longer retries did not establish playable scenes. They are labeled `Needs WebGPU review` in the catalog; their captures are startup evidence, **not gameplay screenshots**. No speculative engine rewrite or claim that all 39 are playable is made. Rustline reached desktop gameplay; its mobile menu/briefing was exercised, but mobile gameplay control was not confirmed. Meridian — Semantic World Compiler (`meridian-2.html`) compiled but displayed stretched triangular terrain artifacts. Its root cause is unresolved and it is labeled `Needs visual review`. Editor checks validate startup and compilation, not exported-world quality or full authoring workflows.

There are 117 screenshot frames from actual browser captures in the existing three-frame format, resized to the repository's 640×480 JPEG quality-58 standard. Frame 0 shows gameplay/editor output where verified, or a startup screen for the six limited titles; frame 1 is startup and frame 2 is a mobile capture. No artwork was invented and no source assets were lossily recompressed.

The existing static audio inventory was regenerated. Its findings are scanner evidence, not a claim that unrecognized embedded/procedural audio is absent. Audio-review browser checks passed: PIN rejection/unlock/lock, keyboard shortcut, filters, search, evidence, reset, desktop and mobile layout; 672 entries, 44 MP3, 25 WAV, 62 either, 20 explicit-placeholder findings, zero page errors. Audio scanner implementation and music-review filters are unchanged. The separate Vesper Lane D-pad and scanner edge-case offers were not included.

Preservation comparison: all 633 unrelated prior catalog objects are identical; both updated games retain paths, IDs and added dates. Existing recent imports remain. The prepared rerun yields **39 unchanged**, zero imports/failures/build requirements (the duplicate sublist identifies the two stable destination aliases). Existing 211 tests and the two new boot regressions pass. See the final validation JSON for the full-suite result and checks.
