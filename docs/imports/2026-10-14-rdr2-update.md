remains: `backupUnreadable` does not check the backup write before removing the
current save. A corrupt/newer current save can be lost when storage cannot allocate
its backup. Normal valid saves and tested v1 migration are unaffected; this is an
upstream recovery-path limitation, not fixed or introduced by this exact import.

The location/loot-marker renderer finding also remains in the generic authoring
path. Both shipped references (`cinder:linen-look`, `cinder:game-spoils-look`) use
`sprite` with shipped asset data, so the installed content does not select the
reported incompatible renderer. Future authored content needs upstream validation.
